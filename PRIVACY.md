# Gizlilik Politikası — Zero File Extractor

*Son güncelleme: 11 Kasım 2026*

*(English version below.)*

Zero File Extractor ("uygulama"), Ali Apaydın tarafından geliştirilen açık kaynaklı bir arşiv aracıdır.

## Kısaca
**Uygulama kişisel veri toplamaz, kimseyle paylaşmaz ve geliştiriciye hiçbir veri göndermez.** Telemetri, reklam, analiz ya da izleme yoktur.

## Bilgisayarınızda saklananlar
Aşağıdakiler yalnızca sizin bilgisayarınızda, uygulamanın kendi veri klasöründe tutulur:
- **Ayarlar:** tema, dil, pencere ve panel konumları, varsayılan çıkarma ve sıkıştırma seçenekleri.
- **Son açılan arşivler:** dosya yolları.
- **Hız ölçümleri:** süre tahmini için, önceki işlerde ölçülen ortalama sıkıştırma ve çıkarma hızı. Dosya adı ya da içerik içermez.
- **Hata günlüğü:** Uygulama hata verirse teknik ayrıntılar yerel bir metin dosyasına yazılır. Otomatik olarak hiçbir yere gönderilmez.
- **Geçici dosyalar:** Arşiv içindeki bir dosyayı açmak, sürüklemek ya da panoya kopyalamak için oluşturulan kopyalar. Uygulama kapanırken, silinemeyenler sonraki açılışta temizlenir.

**Parolalar saklanmaz.** Girdiğiniz arşiv parolası yalnızca o arşiv açıkken bellekte tutulur.

Uygulamayı kaldırdığınızda ya da Windows Ayarlar'dan sıfırladığınızda bu veriler silinir.

## İnternet bağlantısı
Uygulama internete bağlanmaz. Tek istisna, Yardım menüsünden GitHub sayfasını açmanızdır; bu, varsayılan tarayıcınızı açar.

## Dosyalarınız
Dosyalarınız yalnızca siz istediğinizde okunur ya da değiştirilir ve hiçbir yere yüklenmez. RAR oluştururken, bilgisayarınızda kurulu WinRAR'ın `Rar.exe` aracı çalıştırılır.

# Privacy Policy — Zero File Extractor

*Last updated: November 11, 2026*

Zero File Extractor is an open-source archive tool developed by Ali Apaydın.

**The app collects no personal data, shares nothing, and sends nothing to the developer.** No telemetry, ads, analytics or tracking.

- **Stored only on your PC:** settings (theme, language, window layout, default options), the list of recently opened archives, average speed measurements used for time estimates (no file names or contents), a local error log, and temporary copies of files you open, drag or copy out of an archive (deleted when the app closes or at next start).
- **Passwords are not stored.** An archive password is kept in memory only while that archive is open.
- **Network access:** none. The only exception is opening the GitHub page from the Help menu, which launches your default browser.
- **Your files** are read or changed only when you ask, and are never uploaded. Creating RAR archives runs the `Rar.exe` tool of the WinRAR installed on your PC.
- **Contact:** [GitHub Issues](https://github.com/aliapaydin/Zero-File-Extractor/issues)
